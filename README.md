# HasBrains Homebrew tap

Homebrew casks for HasBrains apps.

## Teach Me

[Teach Me](https://teach-me.software/) turns topics into guided courses with Claude Code, tracks learning progress, and shares courses through a community hub.

```sh
brew install --cask endorphin-ai/tap/teach-me
```

To update, run `brew upgrade --cask teach-me`.

## Lomi

[Lomi](https://github.com/endorphin-ai/hasbrains-agent-kit/tree/main/app/lomi) shows your Claude Code usage in the macOS menu bar.

```sh
brew install --cask endorphin-ai/tap/lomi
```

Update:

```sh
brew upgrade --cask lomi
```

Remove:

```sh
brew uninstall --cask lomi
```
